# Data

`Telco-Customer-Churn.csv`: the IBM Telco Customer Churn sample dataset (7,043 customers, 21 columns), a fictional telecom company created by IBM for teaching and demos.

Source: [IBM/telco-customer-churn-on-icp4d](https://github.com/IBM/telco-customer-churn-on-icp4d), distributed under the Apache License 2.0. The same data is published on Kaggle as *Telco Customer Churn*.

The file is included unchanged so the project and its tests run without a separate download.
